# Isaque Felinto

**Mobile robotics developer** — autonomous systems, computer vision and embedded hardware.

I build robotic platforms end to end: mechanical design, electronics and PCBs, firmware, perception and autonomous control. Engineering at [ORC Robotics](https://github.com/ORC-Robotics), SENAI ORC, Brazil.

### What I work on

- **Autonomy** — navigation, motion control and robot software with ROS 2
- **Perception** — computer vision, YOLO object detection and model training
- **Embedded** — firmware and hardware integration on STM32, ESP32 and Raspberry Pi
- **Hardware** — PCB design, mechanical CAD and rapid prototyping
